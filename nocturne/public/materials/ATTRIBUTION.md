# Nocturne surface maps

Derived from 1024 x 1024 Poly Haven maps downloaded on 2026-09-18. Source downloads were verified against API byte counts and MD5 checksums. All sources are CC0-1.0: https://polyhaven.com/license

| Local prefix | Source                                                              |
| ------------ | ------------------------------------------------------------------- |
| stone        | Stone Wall 04 - https://polyhaven.com/a/stone_wall_04               |
| path         | Cobblestone Floor 04 - https://polyhaven.com/a/cobblestone_floor_04 |
| rock         | Marble Cliff 02 - https://polyhaven.com/a/marble_cliff_02           |
| ground       | Forest Ground 05 - https://polyhaven.com/a/forest_ground_05         |

Each has `-color.webp`, `-normal.webp`, and `-roughness.webp` variants converted from the original JPEG maps. Normal maps use OpenGL orientation. Color maps use sRGB; normal and roughness maps are linear. Materials apply repeat tiling and color tints for the moonlit scene.
