# Human traveller

The island character is **Male Adult 02** from the Microsoft Rocketbox Avatar Library, copyright (c) 2020 Microsoft, distributed under the MIT License. The full license is included in `HUMAN-LICENSE.txt`.

Source: https://github.com/microsoft/Microsoft-Rocketbox

Model: `Assets/Avatars/Adults/Male_Adult_02/Export/Male_Adult_02.fbx`

Textures: `m003_body_color`, `m003_head_color`, `m003_opacity_color`, `m003_body_normal`, and `m003_head_normal` from that avatar's `Textures` directory.

Animations from the same repository: `m_idle_breathe_01.max.fbx`, `m_walk_neutral_01.max.fbx`, `m_run_neutral_01.max.fbx`, `m_wave_01.max.fbx`, and `m_sit_chair_breathe_01.max.fbx`.

Adaptation: converted to GLB, embedded and resized textures, physically based materials, filtered animation tracks to the character's skeleton, and removed horizontal root travel so the island controller owns movement. The character is a generic human avatar and does not represent Rakshith's likeness.
